# 霓虹幸存者 // Neon Survivor

一个零依赖的赛博朋克俯视角房间探索射击原型。

## 运行

直接双击 `index.html`，或在目录中启动任意静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

- `WASD` / 方向键：移动，镜头始终跟随人物
- 鼠标：瞄准
- 鼠标左键：射击
- `P` / `Esc`：暂停
- 升级时可按 `1`、`2`、`3` 快速选择

## 首版内容

- 开局可选 3 名角色：均衡型“脉冲”、高速双持“锐刃”、重炮穿透“堡垒”
- 五层地图；每层都有独立房间拓扑，并包含普通房、奖励房和 Boss 房
- 4 种敌人（无人机、疾行单位、重装单位、Boss）
- 三格生命，每次损失生命后获得至少 2 秒无敌时间
- 普通义体升级与奖励房专属核心遗物
- 手动瞄准、暴击、穿透、多弹丸、护甲等构筑属性
- 清空房间解除门禁，击败 Boss 后进入下一层
- 进入战斗房间后有 1.6 秒安全接入时间，敌人从房间外围出现
- 程序化合成的 132 BPM 赛博节奏背景音乐，包含切分低音、鼓组、高帽和循环琶音
- 每层使用不同根音与旋律动机，Boss 房自动切换为更密集的战斗变奏
- 普通伤害使用 18px 提示；暴击使用 26px 发光提示并停留 1.3 秒
- 三名角色拥有独立的战斗轮廓、核心字母标识与弹道色彩
- Boss 拥有独立登场封面、加粗血条和技能预警；降至 30% 生命后切换第二形态
- 五层 Boss 分别使用独立立绘，不再复用同一张封面
- Boss 登场使用 Live2D 风格实时动画：躯干呼吸、头部轻摆、眼部眨动、核心脉冲和专属悬浮部件
- Boss 被击败时立即清空场上全部敌方弹幕
- 五层 Boss 在战斗中使用独立轮廓、颜色、移动 AI、攻击预警和技能循环
- 霓虹屠夫使用预警斩击；虚空执政官使用收缩弹环；熔炉暴君使用冲锋与地雷；量子教宗使用传送螺旋；终焉收割者组合突进与镰线
- Boss 转阶段时拥有 2.2 秒无敌时间并清除场上敌方弹幕，之后攻击与移动进一步强化
- 升级界面开启后的前 0.5 秒锁定鼠标与数字键选择，防止误触
- 奖励房使用独立核心遗物池，包含 STANDARD、RARE、EPIC 稀有度
- 核心遗物采用明确数值与构筑取舍，例如高伤害换低射速、多弹丸换单发伤害、暴击移速换基础伤害
- 程序化赛博朋克视觉、粒子、屏幕震动和合成音效
